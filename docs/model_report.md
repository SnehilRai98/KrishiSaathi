# Crop model report

Generated by `backend/training/make_report.py` from `models/model_card.json` (model `field-v2`, 2026-10-11).
Every number below was measured by `backend/training/evaluate_field_model.py` on photos the model never trained on.

## Summary

| Test set | Original lab-only model | Field-tuned model |
| --- | --- | --- |
| 236 real field photos (PlantDoc test split), right class | 27.1% | **55.5%** |
| Same photos, right crop | 47.0% | **75.0%** |
| 380 clean lab photos (PlantVillage sample) | 93.2% | 90.0% |
| 19 non-leaf photos shown as a confident result | 0.0% | 0.0% |

With 236 photos the margin of error on the field figures is roughly plus or minus 6 percentage points. On a broader 1,080-photo PlantDoc sample (which included training-split photos) the original model scored 13.3% (crop 29.8%), so the original model's field accuracy is somewhere between 13% and 27% depending on the photos. Either way it was not usable in a field.

The lab figure went down slightly after field tuning. The non-leaf set is tiny (a few ordinary photos and graphics), so it proves little.

## Limitations

- Field accuracy was measured on a small public test set (PlantDoc) with 27 of the 38 disease classes. The other 11 classes were learned from lab photos only and are labelled as such.
- Only 14 crops are supported. Photos of other plants, or of several leaves, soil or hands, can still produce a confident wrong answer.
- The non-leaf check uses a handful of ordinary photos and graphics, so it says little about every kind of non-leaf image.
- Confidence was calibrated on a small field validation set; treat it as a rough guide, not a probability.
